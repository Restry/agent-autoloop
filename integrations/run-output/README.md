# 完整执行结果

轮次详情的“查看完整结果 · Agent 回复全文”读取本机执行日志中的最后一份最终回复，并支持 Markdown 下载。与“交付成果”分开：即使没有写报告文件，也能查看 Agent 的文本结论。

当前识别 Claude stream-json 的顶层 result、Codex 已完成 turn 的 agent_message、command 执行器的文本输出。不把工具参数、中间思考、子 Agent 回复冒充任务的最终回复。运行中不提前宣布有最终结果；失败、取消或旧日志缺失时明确说明。

UI 服务每 30 秒检查状态快照中近期结束的轮次，将可识别结果归档至 ~/.agent-autoloop/town-results；手动查看也会补归档。已归档正文不依赖 worker/runs 的日志保留期。已经被清理、且从未归档的旧正文无法凭摘要重建。

每个日志最多读取尾部 4 MiB，每份正文最多保留 400000 个字符；超限会标为截取内容，下载文件名也标 excerpt。结果正文用安全 DOM 渲染，原文中的 HTML 不执行。API 仅接受数字轮次编号，沿用本机主机/来源限制。

验证：第 183 轮的 612 字符完整回复已显示；下载与归档正文一致。解析、排除中间/子任务内容、日志删除后归档仍可读、并发归档测试通过。后端任务和规则未修改。
