# Agent 小镇

Three.js 小镇已接入本机 Agent Auto Loop 中台，保留现有别墅、院落、传送带和工作站的设计。实体数量完全来自 AutoLoop 快照，没有预设项目或空工作站。

## 启动

```sh

node server.mjs
```

打开 http://127.0.0.1:8765/ 。不要再用 Python 静态服务器，它不能转发接口。
服务只监听 `127.0.0.1`。默认后端是 `127.0.0.1:3350`，服务端读取 `~/.agent-autoloop/config.json` 的 owner；浏览器和静态目录不保存密钥。未设置系统自动启动。

## 后端实体与场景

- 一栋别墅 = `lines[].group` 的一个真实取值；同组规则共用别墅。
- 一个工作区 = 一条规则，名称直接使用 `lines[].name`。每页最多显示三个位置；空位置没有业务含义，显示“空工作区”。
- 一个包裹 = `runs[]` 中的一轮，保持原始 run ID。`claimed` 和 `running` 都表示执行中。
- 一座工作站 = `agents[]` 中一个 Agent。品牌模型只决定外观，不预建工作站；未知类型使用通用立体标志。
- 新增、移组、删除以最新快照为准。移除的组和 Agent 会清理对应网格、传送带、标签和控件。
- 没有独立的本地项目层。已删除目录归类、项目别名、初始项目清单、手动移动规则和布局映射文件。浏览器中旧版本的布局缓存不再读取。
- 历史轮次的规则或 Agent 已不在配置中时，不生成占位别墅或空工作站。活动包裹可留在中台；记录明确显示归属未知，完整历史仍可从中台查看。
- 后端若未提供规则的 group，界面明确提示无法定位，不自行猜测或修改配置。

## 数据与操作

先读取 `/v1/state`，再以快照 seq 订阅 SSE。断线主动关闭旧连接，重新读取快照，再按最新序号重建 SSE 订阅；事实到来后串行刷新快照。15 秒健康探测只检查连通性，不替代事件流。
包裹状态来自真实轮次：排队停在项目侧，执行时位于 Agent 塔，终态播放一次返回动画。初次加载的历史完成记录不重放。动画暂停不暂停后端执行。

工作区提供立即运行、暂停/恢复、最近运行。中台面板的运行表单支持 subject/reason；暂停支持 reason/until；补跑支持带时区的 since。中台面板显示真实分组，并提供卡片选项/文字回答/结案、跳过事件补跑、运行记录分页、停止及时间线。暂停规则后立即运行禁用；操作中禁用同一对象，失败显示后端错误。恢复后如有跳过事件，会出现补跑按钮，补跑起点保留在本浏览器。

## 数据覆盖

| 后端数据 | 界面入口 |
| --- | --- |
| totals、spending.today/week | 总览，包括缓存、未报用量轮数、全部累计字段 |
| lines | 分组与规则、院落工作区；调度、暂停、下次触发、每条规则统计 |
| agents | 自动工作站、Agent 列表；电脑、类型、在线时间、完整统计 |
| cards、recentCards | 待处理、卡片历史；问题/通知、事项、说明、选择、回答、处理人和结果 |
| runs、hasMore、nextBefore | 筛选与分页运行记录、包裹、时间线、来源事件、用量和会话链接 |
| timers | 复查定时器 |
| sources、channels | 事件来源、通知通道 |
| pauses、skipped | 暂停与补跑、跳过事件，包含移出规则配置后尚未解除的暂停 |
| unrouted、elsewhere | 未匹配事件、外部任务 |
| seq、now、timezone、healthz.commit | 中台信息 |

各条记录可展开“完整字段”。中台信息还可检查全部快照，未来新增字段不会静默丢失。最近卡片与事件只显示后端快照提供的范围；不是无限历史。运行记录有后端游标分页。

范围是 AutoLoop 本人 HTTP 协议的完整运行管理功能。规则定义/Agent 安装、插件、服务安装卸载、密钥管理仍使用 AutoLoop 原有配置和 CLI，不通过浏览器执行任意 shell。不提供目录归类接口，不修改分组配置。

## 文件与模型

`server.mjs` 是静态服务和接口代理；`dist/layout.js` 从真实 group 生成工作区布局；`dist/hub.js` 管理中台数据及控件；`dist/app.js` 管理三维场景和状态映射。接入前页面代码在 `backups/`。

Three.js 0.170.0 随项目保存，无 CDN。建筑、植物、庭院、纸箱使用 Polyfork GLB；来源和许可见 `dist/models/credits.html` 与 `manifest.json`。四种植物使用公开的 HD 预览 GLB，适用 Polyfork 商业许可，不按 CC BY 再授权。Claude 工作站保留用户提供的 GLB；其他品牌图标来源和许可见 `dist/icons/NOTICE.md`。

## 声音设置

右下角喇叭打开设置面板。自然庭院、机械工坊、电子控制室、柔和提示四种主题均为本机 Web Audio 合成。任务开始、任务结束、背景声音、操作与消息提示分别有开关和音量，总开关可关闭所有声音。切换主题保留类别开关；设置保存在当前浏览器 localStorage。隐藏页面会静音，试听不会触发中台任务。机械与电子主题的背景使用振荡器，不使用持续白噪音。

浏览器离线音频检查见 checks/audio-render.html：覆盖四种主题的开始、结束、背景，共 12 组有声/静音渲染，并检查音量峰值、主题切换和持久化。
