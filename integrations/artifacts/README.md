# 轮次交付成果

本机 worker 在第一轮启动前保存工作目录文件基线，在完成、失败或取消时保存新增/修改文件的不可变快照。所有执行器共用此入口，重试按 attempt 分开。快照位于 ~/.agent-autoloop/artifacts/<run>-<attempt>/，不随 worker/runs 的 14 天日志清理而删除。API 只通过已登记文件 ID 提供本机快照，不接受任意文件路径；下载时检查 SHA-256。此版本不传输其他电脑上的成果。

## 安装与生效

将 store.mjs 复制到 ~/.agent-autoloop/app/worker/artifacts.mjs，在该引擎目录检查并应用 worker.patch。该补丁独立于 Claude 环境变量补丁。新 worker 进程才会启用收集；正在执行的旧轮次没有起始基线，不伪造文件归属。服务升级后需要重新检查补丁。

## 收集范围

- 工作目录内普通文件，新增和修改均收集；不扫描任意外部路径，不从摘要猜文件路径。
- 不收集隐藏文件/目录、Git、依赖目录、缓存目录、已识别的凭据文件、数据库和符号链接。
- 扫描上限 10000 项，目录深度 24；每文件 50 MB，每批最多 200 文件/200 MB。达到限制和读取失败写入成果说明。基线扫描不完整时，无法核实的新文件不归入本轮。
- 相同工作目录的并发任务会标注归属重叠。该机制证明文件在执行窗口发生变化，不能证明唯一作者。
- 成果只是文件快照，不代表任务成功或文件内容已验收。失败和取消也保留快照。
- 历史补录需人工核实回执中的明确文件位置，标为补录时版本。当前已补录 132、136、151、167 轮报告。其他旧轮次显示未收集。

## 界面

轮次记录 → 具体轮次 → 交付成果。支持 Markdown、文本/代码、JSON、图片、隔离 HTML 和 PDF 预览；其他格式下载到对应应用打开。文本预览最多 1 MB，原件下载不截断。HTML 禁用脚本、网络和表单；原始文件只以附件下载。报告总览保留为日报/早报快捷入口。

## 验证

node --test checks/artifacts.test.mjs
node checks/artifacts-worker.mjs

后者启动隔离临时 HOME 中的真实 worker 和子进程，验证文件从执行到快照的完整链路，不运行业务 Agent。
